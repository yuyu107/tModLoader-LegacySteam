# 更新记录

## 0.2.0（2026-11-10）

- 解除对 tModLoader 本体单一 SHA-256 的限制，在 Steamworks 库仍受支持时自动定位并更新本体校验值。
- 按游戏原文件 SHA-256 分目录保存备份，自动选择安装、重复安装与恢复所需的原文件，保留旧版备份兼容。
- 根据系统界面语言显示简体中文、繁体中文或英文提示。
- 补充 Steam 自动更新、验证文件后的重新修补方法，以及 Steam 验证完整性恢复方式。
- 保留对三份 Steamworks 库的严格校验与接口预检；不承诺所有未来 SDK 或游戏逻辑兼容。
- 汇总此前 0.2.0-test1 / test2 / test3 的功能为正式版。

## 0.1.0（2026-10-05）

- 首个正式版安装包，沿用 Test2 已实测的四个文件修改结果，差分内容和目标哈希保持一致。
- 安装包包含 MIT 许可证、中文使用说明、更新记录和校验清单。
- 提供 ZIP 的 SHA-256 校验文件及无需游戏 DLL 的重新打包命令。

v0.1.0 差分安装器已通过 Windows 7 SP1 64 位、Windows 8.1 64 位实测；启动、配合 SteamLegacyZstd 下载模组、模组加载和进入游戏已验证。仅支持 tModLoader 2026.8.3.0，不支持 32 位 Windows；Win7 测试环境需要配合 VxKex。Steam 联机、邀请和云存档尚未验证。

## 0.1.0-test

- 首次公开源码，基于已实测成功的 Test2。
- 适配 2024 年 11 月 Steam 的好友、UGC、Remote Play 接口。
- 允许缺失时间线接口，并停用相关新功能。
- 保留完整性校验，将预期哈希精确更新为补丁 DLL 的哈希。
- 改用差分补丁，安装包不再包含完整游戏或 Steamworks DLL。
- 安装前校验版本、预检接口，生成并验证全部输出后再替换；提供备份与恢复。
- 支持读取 Test1 / Test2 备份进行升级。

已验证 Test2 在 Win7 SP1 64 位、Steam 1730853000、tModLoader 2026.8.3.0 上启动，配合 Zstd 补丁下载并使用模组。差分安装器尚待实机验证；联机、邀请和云存档尚未验证。
